# Подключение AI к CriteriaLab

Статус: серверный слой и интерфейс опубликованы на основном сайте. Исправление от 16 ноября 2026 года проверено локально и ожидает публикации: полный текст работы больше не входит в запрос генерации итогового отзыва, а выбор провайдера полностью выполняет backend.

## Что реализовано

- Netlify Function `/.netlify/functions/ai`: API-ключи остаются на сервере.
- Единый интерфейс с действиями `recognize` и `assess`.
- Адаптеры Gemini Flash и Cloudflare Workers AI.
- Gemini использует актуальный Interactions API с `store: false` и JSON Schema.
- Ограничение изображения для AI до 4 МБ; JPG и PNG.
- Распознавание не исправляет ошибки ученика и помечает нечитаемые места.
- Оценивание запускается только после подтверждения текста преподавателем.
- AI возвращает структурированный черновик: баллы, комментарии, точные цитаты, исправления, сильные стороны, зоны роста и рекомендации.
- Баллы проверяются по диапазонам критериев; замечания без точной цитаты из текста отклоняются.
- AI-оценка не считается утверждённой: преподаватель должен проверить и подтвердить её вручную.

## Настройка Netlify

В `Site configuration -> Environment variables` добавить:

### Gemini

- `AI_PROVIDER=gemini`
- `GEMINI_API_KEY=<секретный ключ>`
- `GEMINI_MODEL=gemini-3.8-flash`

### Cloudflare Workers AI

- `CLOUDFLARE_ACCOUNT_ID=<account id>`
- `CLOUDFLARE_API_TOKEN=<секретный токен>`
- `CLOUDFLARE_OCR_MODEL=@cf/moondream/moondream3.1-9B-A2B`
- `CLOUDFLARE_ASSESS_MODEL=@cf/meta/llama-3.1-8b-instruct-fast`

В Cloudflare распознавание и оценивание выполняют разные модели. Moondream 3.1 используется только для OCR изображения; быстрая текстовая Llama 3.1 получает только подтверждённый преподавателем текст и готовит черновик оценивания. Vision-модель Llama 3.2 оставлена только как явно настраиваемый резервный вариант.

Перед первым использованием этой модели необходимо один раз принять лицензию Meta в Cloudflare Workers AI, отправив модели запрос с `{"prompt":"agree"}` согласно инструкции Cloudflare.

После явного согласия владельца аккаунта установите `CLOUDFLARE_LLAMA32_AGREED=true`. Только при этом флаге сервер может отправить одноразовый `agree` в ответ на требование Model Agreement для точного ID `@cf/meta/llama-3.2-11b-vision-instruct`.

Пользовательский интерфейс не показывает технический выбор провайдера. Для OCR backend сначала выбирает Cloudflare с его специализированной моделью распознавания, затем Gemini как резерв. Для предварительного оценивания применяется `AI_PROVIDER`, а для итогового отзыва backend сначала пробует Gemini, затем доступный резервный провайдер. Запрос итогового отзыва содержит только утверждённые критерии, замечания и итоговые поля преподавателя; полный текст работы не передаётся.

## Проверка на реальных моделях

1. Использовать только обезличенные копии трёх тестовых фотографий.
2. Запустить каждую фотографию отдельно через Gemini и Cloudflare.
3. Сохранить ответы моделей без исправлений.
4. Сравнить с ручной расшифровкой по пропущенным, добавленным и неверным словам, пунктуации и порядку строк.
5. Только после выбора OCR проверить выставление баллов по одной и той же рубрике.

Бесплатный Gemini API не следует использовать с персональными или конфиденциальными данными учеников. Перед реальным использованием необходимо согласовать правила обработки данных и выбрать подходящий платный либо локальный режим.
