# CriteriaLab

CriteriaLab — веб-помощник преподавателя для критериального оценивания письменных работ и подготовки обратной связи.

Преподаватель добавляет работу и критерии, выставляет баллы и комментарии, подтверждает итог, а затем формирует отзыв для ученика. Окончательное решение всегда остаётся за преподавателем.

## Онлайн-версия

[Открыть CriteriaLab](https://dapper-pastelito-d5f921.netlify.app/)

## Возможности

- ввод задания, текста работы и сведений об ученике;
- просмотр загруженных изображений оригинала;
- редактирование критериев, дескрипторов и максимальных баллов;
- импорт критериев из JSON, TXT, DOCX и PDF с текстовым слоем;
- ручное оценивание с комментариями, цитатами и исправлениями;
- автоматический подсчёт итогового балла;
- обязательное повторное подтверждение после изменения оценки;
- формирование, редактирование и скачивание отзыва;
- печать или сохранение отзыва в PDF средствами браузера;
- сохранение и восстановление черновика в JSON;
- синтетический демонстрационный пример;
- опциональный серверный слой для AI-распознавания и черновика оценивания.
- серверный автоматический выбор провайдера без технических настроек в пользовательском интерфейсе;
- генерация итогового отзыва только из утверждённых критериев, замечаний и рекомендаций: полный текст работы в этот AI-запрос не передаётся.

## Быстрый локальный запуск

Требуется установленный [Node.js](https://nodejs.org/).

```powershell
node criteria-server.cjs
```

После запуска откройте:

<http://127.0.0.1:4174/>

Локальный сервер показывает основную ручную версию приложения. Для проверки серверных AI-функций используйте локальную среду Netlify и настройте переменные окружения отдельно.

## Проверка проекта

Автоматическая проверка основного сценария:

```powershell
node check-criterialab.cjs
```

Проверка адаптеров AI без реальных сетевых запросов и секретных ключей:

```powershell
node test-ai-providers.mjs
```

Контрольный сценарий использует демоработу `DEMO-01`: исходный результат 15/20, затем первый критерий меняется с 3 на 4 и итог пересчитывается до 16/20. Старый отзыв блокируется до повторного подтверждения оценки.

## Настройка AI

AI-функции необязательны: основной ручной процесс работает без них. Поддерживаются адаптеры Cloudflare Workers AI и Gemini.

1. Скопируйте названия переменных из `.env.example` в переменные окружения Netlify.
2. Добавьте секретные ключи только в настройках хостинга.
3. Не сохраняйте реальные ключи в `.env.example`, HTML, Git или публичных архивах.
4. Выполните тесты перед публикацией.

Подробности приведены в [AI-SETUP-RU.md](AI-SETUP-RU.md).

AI создаёт только черновик. Распознанный текст, комментарии и баллы необходимо проверить и подтвердить вручную. Доступность отдельных моделей и функций зависит от настроек провайдера и текущей опубликованной версии.

## Публикация на Netlify

Netlify использует следующие каталоги из `netlify.toml`:

- `publish-criterialab` — статический сайт;
- `netlify/functions` — серверные функции.

Перед публикацией убедитесь, что содержимое `publish-criterialab` соответствует рабочим файлам в корне проекта, тесты проходят, а необходимые переменные окружения заданы в Netlify.

## Конфиденциальность

Не отправляйте персональные или конфиденциальные данные учеников во внешние AI-сервисы без подходящего правового основания, согласованных правил обработки и разрешения вашей организации. Для испытаний используйте только обезличенные копии работ.

Черновики хранятся локально в загружаемом JSON-файле. В проекте нет аккаунтов, базы данных, облачного хранилища или синхронизации между устройствами.

## Ограничения

- качество результата зависит от критериев и проверки преподавателя;
- распознавание рукописи может содержать пропуски, перестановки и выдуманный текст;
- PDF-сканы без текстового слоя не подходят для обычного импорта критериев;
- загруженное изображение не включается в JSON-черновик;
- итоговый отзыв формируется на английском языке напрямую из утверждённых преподавателем комментариев, цитат и исправлений, без отдельного AI-перевода;
- шкала по умолчанию не является официальной шкалой IELTS, Cambridge или CEFR;
- проект является учебным прототипом, а не полностью готовой информационной системой школы.
